# v3.0.0 "Cornerstone" — the API major and the release-candidate core

The MAJOR milestone of the line ([ADR 0043](../../docs/adr/0043-v3-is-the-api-major-and-a-release-candidate-core.md)):
the API major plus a release-candidate MiSTer core. Both bitstreams are swept at
the release's own build date and labelled **release candidate, not
hardware-verified**. Hardware verification is a later v3.x release
([`v3.x-hardware-verification-plan.md`](v3.x-hardware-verification-plan.md)).

The planned API and format break already shipped in v2.9.8, and each item was
verified against the tree on 2026-10-05:
- ADR 0042's removals, `SystemBus` and BUS v2;
- `Header` and `FrameInput` `#[non_exhaustive]`;
- the `.fm2` Four Score P3/P4 import.

This release therefore:
- lands the held T-MMC3-BG-A12 work in both repositories;
- closes the version-compatibility gap that work opens;
- takes the last struct-extensibility breaks before 4.0;
- cuts a new bitstream pair (the RTL changes);
- restates every break since v2.x in its notes;
- submits the libretro sync;
- tags both repositories together.

The codename is "Cornerstone" (maintainer, 2026-10-05; "Keystone" was
proposed first and set aside because v2.4.7 already carries it).

## Research rule

Research continues through the whole release, not only at planning. Order:
1. the repo's and the sibling's documents, the vendored `nesdev_wiki/` and
   `ref-docs/`;
2. the open Internet: NESdev wiki and forums, datasheets, libretro
   documentation, and Context7 for crates;
3. black-box comparison against reference emulators' output.

Reference-emulator source and third-party NES HDL are never opened, and
`~/Code/Forks-Projects/ref-emulation/` is never searched. Before reading any
oracle file to inform RTL work, run `grep -n "Provenance:"` on it.
