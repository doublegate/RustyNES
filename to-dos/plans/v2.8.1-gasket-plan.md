# v2.8.1 "Gasket" — the libretro core fits the frontends around it

The second release of the v2.8.x line
([ADR 0041](../../docs/adr/0041-hardware-release-is-v3.0.0.md);
[line plan](v2.8.x-libretro-rtl-audit-plan.md)). It works from
[`libretro-audit-report.md`](../../docs/audits/libretro-audit-report.md) §2.3,
§2.5 to §2.7, §3 and the executive summary's input claims, and the
[libretro ledger](../../docs/audits/libretro-disposition.md) rows targeted at
v2.8.1. Oracle only; the MiSTer sibling does not change.

## What v2.8.0 closed and did not

v2.8.0 "Bulkhead" closed the FFI-safety rows (L-1.1 to L-1.3, L-2.1, L-2.2,
L-2.4; L-1.4 partial, L-1.5 accepted). Thirteen rows remain, every one
targeted here.

## What planning found before any code

Every claim was checked against the code, the tools, or the upstream
documentation before any work was planned. The audit is right about most of
the build defects and wrong about several of its remedies.

## The deliverable

1. **Makefile:** `LIB_PREFIX` for the file prefix, `win` accepted as
   `windows`, `DEBUG=1` builds and copies the debug core, and
   `CARGO_TARGET_DIR` honoured. Pinned by a test that runs `make -n` for each
   case (skipped where `make` is absent).
2. **Metadata:** `unf|unif` in the `.info` and in `valid_extensions`, pinned by
   the existing `.info` audit and a harness load of a committed CC0 `.unif`.
   The resubmit script fixed.
3. **Input:** the duplicate poll removed; joypads read by bitmask (one call per
   port, with the per-button fallback when a frontend lacks bitmasks);
   descriptors for all four ports; the Zapper detached when a port is switched
   away from it; a `rustynes_four_score` core option. Pinned in the C-ABI
   harness by counting the frontend callbacks.
4. **Audio:** full scale at `1.0`, as on the desktop, pinned by a harness test
   that counts clipped samples on `db_n163`. This makes the libretro core about
   6 dB quieter than before.
5. **Performance** (L-2.3, L-2.6, the audio half of L-2.7): each measured
   before any change, and adopted only under `scripts/perf/ab_check.sh`'s rule
   with byte-identical output. A rejected item is recorded with its number.
6. **Docs:** `docs/libretro/` brought current (L-3.5b); the ledger closed.

## The gate

- Every CONFIRMED row has a test that fails before its fix, and each fix is
  mutation-checked by reverting it.
- `--features test-roms` full suite, AccuracyCoin 144/144, nestest pass.
  Emulation does not change; the libretro loudness does, on purpose.
- fmt, clippy for every CI feature set, rustdoc, `no_std`, the libretro
  cross-check with the unwind override.

## Out of scope

New buildbot targets (L-3.2); turbo and SOCD; `rust-libretro`'s exported hook
(L-3.3); the upstream `.info` sync, which waits for v3.0.0.
