# v3.0.0 — the SuperStation One core

The release in which a `RustyNES_MiSTer` bitstream is **verified on real
hardware**: the first shipped artefact of a new class, which is why it is a MAJOR
version ([ADR 0041](../../docs/adr/0041-hardware-release-is-v3.0.0.md)). It is
reached through three audit and hardening lines:
[v2.7.x](v2.7.x-core-frontend-audit-plan.md),
[v2.8.x](v2.8.x-libretro-rtl-audit-plan.md) and
[v2.9.x](v2.9.x-final-audit-and-hardware-plan.md).

## The deliverable

| Artefact | Status at v3.0.0 |
| --- | --- |
| **On-die `.rbf`** (`USE_SDRAM_CART = 1'b0`) | **The headline.** Every bring-up strand A–F passed on the SuperStation One |
| **Off-die `.rbf`** (the SS1's 128 MB SDRAM) | **Secondary, labelled experimental.** MemTest and its own Strand B rows passed |
| Oracle and sibling | Tagged v3.0.0 together |

## The gate

- Every row of `RustyNES_MiSTer/docs/bringup-log.md` is PASS with its named
  artefact, recorded against the bitstream md5 read off the console.
- The co-simulation ladder is green on the tagged commit, taken from the
  `TOTAL:` line, not a document.
- AccuracyCoin read back from the board as bytes, diffed against the golden.
- Strand F's incumbent re-measure and feature delta are written up honestly.
- `to-dos/mister/contribution-checklist.md` is complete. Every box that can be
  evidence about this core is ticked or carries a reason; the two-board box stays
  open unless a second board has actually run it.

## What changes in the same PR

- **Every "no hardware has run any bitstream" anchor flips**, located at the time by
  `grep -rn "no hardware has run\|No hardware has run" README.md docs/` in both
  repositories rather than by a remembered list (`bringup-log.md` §"The anchors
  that become false on first boot").
- If v2.9.0 decided to remove the v2.7.5 deprecations, the removal lands here, with
  a CHANGELOG migration note.

## After the tag

- **The libretro `.info` upstream sync**, deferred until the MiSTer core was
  complete. That is now.
- **The MiSTer-devel submission**, if Strand F's decision says go. Retro Remake
  remains a planned second home either way.
- **Release assets:** the oracle release carries `RustyNES_MiSTer-v3.0.0.rbf` (and
  the off-die variant under a name chosen at v2.9.2); the sibling release carries
  both its datecoded and version-named copies via `scripts/release-rbf.sh`.

## Deferred past v3.0.0

FDS, expansion audio, save states, cheats, Vs. System, NSF, Zapper, Four Score,
paddle, keyboard and PAL on the FPGA; the remaining mapper families; the
DE10-Nano second board.
