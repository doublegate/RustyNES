# v2.9.5 "Caliper" — every open accuracy failure investigated, then fixed or pinned with its cause

The second release of the line to v3.0.0
([line plan](v2.9.4-to-v3.0.0-line-plan.md), v2.9.5 row). v2.9.4 changed no
emulation behaviour; this one is allowed to, under the rules the maintainer set
on 2026-09-29.

## Maintainer decisions (2026-09-29)

| Question | Decision |
| --- | --- |
| Accuracy fixes that change output | **Allowed.** Each fix is red-first. Every golden it moves is re-blessed in the same commit and listed in the release notes. AccuracyCoin 144/144 and nestest 0-diff must hold |
| MMC3 R1/R2 "M2-edge low-time filter" lever | **Try it; keep it only if clean.** Kept only if the four ignored R1/R2 tests pass and nothing else changes. Otherwise it is recorded as refuted, with its measurement, and the lever is closed |
| Bitstreams | **Sweep only if the RTL changed.** If sibling RTL changes, both builds are seed-swept at the release date and new `.rbf`s ship. If not, the v2.9.2 pair ships byte for byte, as in v2.9.3 and v2.9.4 |
| Codename | **Caliper** |

## What v2.9.4 left

These are the open items in `docs/accuracy-ledger.md`, `to-dos/ROADMAP.md` and
the sibling's `docs/oracle-vs-documentation.md`, as listed in the line plan.
Each gets one of three outcomes:

- **fixed** — a test failed first, and reverting the fix is caught;
- **pinned** — a test records the current behaviour, with the cause named;
- **closed** — the item is refuted or out of reach, with the evidence.

"Investigated" with no outcome does not count.

## Risks

- **AccuracyCoin's APU page.** It exercises the same frame-counter paths the
  `apu_test` fix touches, and it is re-run after every core change.
- **MMC3 timing.** It has absorbed more than 21 falsified levers (ADR 0002).
  Anything here is measured against the whole MMC3 battery, never against one
  ROM.
- **Sibling goldens.** They are exported from a pinned oracle commit. A core
  change moves them only once the pin moves, so the pin is not moved as a side
  effect.

## Out of scope

- Hardware: v3.x.
- New mapper families: that is v2.9.6.
- Performance: that is v2.9.8.
