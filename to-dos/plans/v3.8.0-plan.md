## Power-user rows (D33, added 2026-10-17)

Added by the maintainer's D33 selection, beside this release's own rows; they come after them if the release runs long. Tickets in `to-dos/ROADMAP.md` ("Power-user line").

| Ticket | Item | Gate |
| --- | --- | --- |
| `T-HOMEBREW-HAZARDS` (M) | Homebrew hazard finder: run a ROM under K power-on seeds, CPU/PPU alignments and RAM-init patterns and report the first read whose result depends on them; an FPGA-safe check that runs it through the co-simulated MiSTer RTL and reports divergence (never certifying hardware); and a homebrew CI GitHub Action (headless runs, Lua assertions, golden-frame/audio diffs on a pinned epoch) | Test ROMs that read uninitialised RAM, depend on alignment and on open bus are each flagged at the right read; a clean ROM is not |
| `T-TAS-BRANCH-TREE` (M) | TAS branch tree: branches as a tree with diff and merge of input ranges between branches, all scriptable from Lua | Merging a branch's frames into another reproduces the expected input log; the Lua API can add, save, remove and diff branches |
| `T-GHOST-RACE` (M) | Ghost racing (a lockstep second instance replays a recorded run; its player sprites, chosen by a per-game RAM map, are composited translucently) and same-seed race / daily-challenge mode through the lobby Worker | The ghost stays frame-locked to its source movie for a whole run; two entrants given the same challenge start from byte-identical states |
