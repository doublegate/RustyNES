## Power-user rows (D33, added 2026-10-17)

Added by the maintainer's D33 selection, beside this release's own rows; they come after them if the release runs long. Tickets in `to-dos/ROADMAP.md` ("Power-user line").

| Ticket | Item | Gate |
| --- | --- | --- |
| `T-NETPLAY-DESYNC-FORENSICS` (S-M) | Automatic desync forensics: on a checksum mismatch, peers exchange states (opt-in) and a report names the first diverging subsystem byte and frame | A planted one-byte divergence in a loopback session is reported at the right subsystem, address and frame |
| `T-NETPLAY-EDGE-SPECTATE` (M) | Edge-relayed spectators: a Durable Object fans out confirmed inputs only; each viewer simulates locally and can seek, rewind and switch views | A spectator joining mid-session reaches the players' confirmed digest and stays matched for N frames; the relay carries inputs only |
| `T-HACK-BPS-RECORDER` (S-M) | A live-patch recorder for debugger edits, and regression replay of reference movies against a patched ROM reporting the first divergent frame and its cause. PRG and CHR edits are written as a BPS patch; RAM pins are not ROM bytes and BPS has no runtime-RAM semantics, so they are written to a sidecar in the existing raw RAM cheat format (address, value, compare), referenced from the BPS metadata by name and hash | A recorded BPS applied to the clean ROM reproduces the edited image byte for byte; a RAM-only fixture (one pinned address, no ROM edit) replays with the pin applied from the sidecar, read back at the pinned frame; a planted regression is located |
