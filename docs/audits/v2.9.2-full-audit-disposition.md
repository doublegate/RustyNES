# v2.9.2 full audit -- disposition ledger

What was done with each finding of
[`v2.9.2-full-audit-report.md`](v2.9.2-full-audit-report.md). The report is kept
exactly as written; this ledger is where a claim is confirmed, refuted or
deferred, with the evidence. Triage rules: [`README.md`](README.md) and the
[v2.9.2 plan](../../to-dos/plans/v2.9.2-candidate-plan.md).

Verdicts: **FIXED** (a test failed first, the fix passes it, and a mutation of
the fix is caught), **REFUTED** (the claim is false against the tree, with the
evidence), **NOT A DEFECT** (the behaviour is as described but correct or
intended), **DEFERRED** (with who decided and to when), **DECLINED** (a real
suggestion not taken, with the reason), **CHANGED, UNVERIFIED** (code changed where
no gate on this machine can run it; it is not FIXED until its named check runs).
