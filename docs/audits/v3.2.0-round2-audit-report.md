#### APU-R2-01: False Sharing & Cache-Line Contention Between Emulator and CPAL Audio Threads

- **Severity / Category**: High / Concurrency & Cache Coherency
- **Target File & Line Numbers**: `crates/rustynes-frontend/src/audio.rs:168-175`

**Observation & Root Cause Analysis**:

In `QueueInner`, the consumer index `head: AtomicUsize` and the producer index `tail: AtomicUsize` are stored consecutively in memory, immediately following the 24-byte `Ring` struct:

```rust
struct QueueInner {
    ring: Ring,
    head: AtomicUsize, // Offset 24
    tail: AtomicUsize, // Offset 32
    overrun_dropped: AtomicU64,
    underruns: AtomicU64,
}
```

Both `head` and `tail` occupy the same 64-byte L1/L2 data cache line. The emulation worker thread executes `push()` (frequently writing to `tail`), while the CPAL real-time audio thread executes `pop_or_silence()` (frequently writing to `head`). On multi-core CPUs, this causes constant cache-line invalidation (false sharing ping-pong) between CPU cores via the MESI cache protocol, introducing latency jitter into the audio thread.

**Research Citations & Specifications**:

*Intel 64 and IA-32 Architectures Optimization Reference Manual*, Section 3.7.3 ("Preventing False Sharing"): Atomic variables modified by distinct concurrent threads must reside on separate 64-byte cache lines to eliminate bus invalidation penalties.

- **Severity / Category**: Medium / SIMD Auto-Vectorization & Bounds Elision
- **Target File & Line Numbers**: `crates/rustynes-apu/src/blip.rs:292-314`

**Observation & Root Cause Analysis**:

`RING_SIZE = 4096`, `TAPS = 32`. In 4065 out of 4096 cases (**99.24% of all impulse scatters**), `start <= 4064`, so the 32-tap window is contiguous and does not wrap. - **Severity / Category**: Medium / Micro-Optimization & Branch Removal
- **Target File & Line Numbers**: `crates/rustynes-apu/src/mixer.rs:128-140, 217-221`

**Observation & Root Cause Analysis**:

`OnePole::process` evaluates `if self.is_hpf` on every audio sample. Evaluating `if self.is_hpf` three times per sample on every output tick is completely redundant.

**Research Citations & Specifications**:

Agner Fog, *Optimizing Subroutines in Assembly Language*: Replace invariant runtime condition flags inside DSP loops with dedicated monomorphic subroutines to avoid branch prediction table pollution.

**Concrete Drop-In Patch**:

```rust

        self.prev_out = y;
        y
```

#### APU-R2-06: Excessive 128 KiB Ring Buffer Footprint From `AtomicU64` Storing 32-Bit Samples

- **Severity / Category**: Medium / Memory Footprint & L1 Cache Locality
- **Target File & Line Numbers**: `crates/rustynes-frontend/src/audio.rs:142-161, 470-480, 540-550`

**Observation & Root Cause Analysis**:

`Ring::slots` is allocated as `Box<[AtomicU64]>` with `DEFAULT_CAPACITY = 16_384`. Standard L1 data cache is 32 KiB or 48 KiB on modern x86 and ARM processors. This 128 KiB buffer overflows L1D cache, causing L2 cache misses on audio stream pushes and pops. Storing raw float bits in `AtomicU32` halves the footprint to 64 KiB.

**Research Citations & Specifications**:

*Computer Architecture: A Quantitative Approach*: Keeping streaming ring buffers compact reduces L1D/L2 cache evictions during audio frame processing.

- **Severity / Category**: High / WebGPU Specification Compliance & Driver Portability
- **Target File & Line Numbers**:

  - `crates/rustynes-gfx-shaders/src/lib.rs:280` (`NTSC_LMP_WGSL`)

  - `crates/rustynes-gfx-shaders/src/crt_royale.wgsl:137`

**Observation & Root Cause Analysis**:

```wgsl

    return vec4<f32>(0.0, 0.0, 0.0, 1.0);
```

`textureSample` calculates implicit screen-space derivatives across the 2x2 fragment quad. Invoking `textureSample` in non-uniform control flow violates WGSL §13.3, causing undefined derivative behavior, border rendering glitches, or compilation failures on strict drivers (Metal, Vulkan, Android Mali/Adreno). Because NES textures have no mipmaps, `textureSampleLevel(nes_tex, nes_smp, suv, 0.0)` is strictly legal and faster.

**Research Citations & Specifications**:

W3C WebGPU Shading Language (WGSL) Specification, Section 13.3 ("Texture Sample Operations"): Implicit derivative operations must only be executed in uniform control flow.

- **Severity / Category**: **Critical** | Netplay Performance & Rollback Overhead
